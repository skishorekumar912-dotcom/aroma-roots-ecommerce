# AROMA ROOTS 🌶️

### Authentic Spices. Effortless Cooking.

Aroma Roots is a modern masala and spices e-commerce website designed to showcase spice products and provide customers with a simple online shopping experience.

## 📌 Project Overview

Aroma Roots provides a digital platform for customers to explore different categories of masala and spice products, view product information, add products to their cart, and place orders.

The project is developed as a full-stack web application using **Next.js, TypeScript, Tailwind CSS, Node.js, Express.js, and MySQL**.

## ✨ Key Features

* Modern and responsive e-commerce interface
* Product category browsing
* Product listing and product details
* Shopping cart functionality
* Product search
* Customer-friendly navigation
* Recipe and food-related content support
* Contact and enquiry sections
* REST API-based backend
* MySQL database integration
* Admin-side product and order management architecture

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/skishorekumar912-dotcom/aroma-roots-ecommerce.git
```

### 2. Navigate to the project

```bash
cd aroma-roots-ecommerce
```

### 3. Install frontend dependencies

```bash
npm install
```

### 4. Start the frontend

```bash
npm run dev
```

The frontend will run locally using the Next.js development server.

### 5. Backend Setup

Navigate to the backend folder:

```bash
cd backend
```

Install backend dependencies:

```bash
npm install
```

Configure the required MySQL database and environment variables before starting the backend server.
